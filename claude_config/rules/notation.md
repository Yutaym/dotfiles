# セッション番号・ウィンドウ番号の書き方

## セッション番号の書き方

- `SNo<数字>` は、セッション番号（session-overview の表の No）を指す（例: `SNo3`）。大文字・小文字は区別しない（`sno3`・`SNO3` も同じ）。
- 数字の前の空白と `.`、全角の文字も同じものとして読む（`SNo 3`・`SNo.3`・`ＳＮｏ３`）。
- 番号で指定されたら、返答では「SNo3（dotfiles-overview-waiting）」のように、セッション名を添えて書く。
- 次のときは、作業を始める前にユーザーに確かめる。
  - 指定された番号のセッションが、今の一覧にないとき
  - 少し前の話に出た番号で、そのセッションがもう終わって、番号が使い回されているかもしれないとき
- 番号はこのマシンでだけ決まっているので、ほかのマシンのセッションに送るメッセージでは、番号ではなくセッション名を書く。

## ウィンドウ番号の書き方
- `WNo<数字>` は、このマシンの tmux（Windows では psmux）の、今のセッションのウィンドウ番号を指す（例: `WNo2`）。書くときは `WNo` と書く。ユーザーが小文字（`wno2`）や大文字（`WNO2`）で書いたときも同じものとして受け取る（2026/11/20 にユーザーが決めた）。
- 数字の前の空白と `.`、全角の文字も同じものとして読む（`WNo 2`・`WNo.2`・`wno 2`・`wno.2`・`ｗｎｏ２`）。
- 返答でウィンドウを指すときは `WNo<数字>` と書き、「WNo2（claude-vim-mode）」のようにウィンドウ名を添える。
- ウィンドウの番号は 1 から始まり、ウィンドウを閉じると番号が詰まる（`renumber-windows on`）。少し前の話に出た番号は今と違うことがあるので、`command tmux list-windows` で今の番号と名前を確かめてから使う。食い違うときはユーザーに確かめる。
- ssh 先の tmux のウィンドウは「Home_Mac_1 の WNo2」のようにマシン名を前に付ける。付いていなければこのマシンの番号として読む。
