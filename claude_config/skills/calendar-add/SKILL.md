# calendar-add

Google カレンダーに予定を追加する。claude.ai の Google カレンダーコネクタ（`mcp__claude_ai_Google_Calendar__*`）を使う。Spark MCP は読み取り専用で予定を作れないので使わない。

ツールが読み込まれていなければ、ToolSearch で 1 回にまとめて読み込む:
`select:mcp__claude_ai_Google_Calendar__list_calendars,mcp__claude_ai_Google_Calendar__list_events,mcp__claude_ai_Google_Calendar__create_event`

## 1. コネクタが使えるか確かめ、カレンダーの一覧を取る

- `list_calendars` を呼ぶ。
- コネクタのツールが `authenticate` だけになっている、または認証のエラーが出たときは、そこで止める。ユーザーに `/mcp` →「claude.ai Google Calendar」で認証してもらうよう伝える（Claude からは認証を始められない）。認証が終わったら、続きをする。
- `list_calendars` は書き込めるかどうか（accessRole）を返さない。購読しているだけの次のカレンダーは、名前で候補から外す。
  - 「日本の祝日」「月の位相」、ほか `@group.v.calendar.google.com` で終わる ID のもの（Google が出している読み取り専用のカレンダー）

## 2. 登録先のカレンダーを決める

- ユーザーがカレンダーの名前を書いていて、一覧の summary と合えば（大文字・小文字や表記の小さな違いは同じとみなす）、それに決めて選択は飛ばす。
- 書いていなければ、AskUserQuestion で選んでもらう。選択肢は、よく使う次の 3 つにする（一覧にあるものだけ）。ほかのカレンダーは「Other」で名前を入れてもらう。質問文には、ほかの候補の名前も並べて書く。
  1. Naist Google Calender
  2. 個人予定
  3. Work
- 「Other」で入った名前が一覧と合わなければ、候補を番号付きの表で出して、もう一度聞く。
- calendarId は、毎回 `list_calendars` の結果から引く（スキルには書かない。ID が変わったり、カレンダーが増えたりするため）。

## 3. 予定の内容を読み取る

貼られた文から、件名・日時・場所・メモ（description）を読み取る。

- **年**: 書いていなければ、今日より後で一番近い年にする。曜日が書いてあれば、その年で曜日が合うか確かめる。合わなければ、合う年を探して確かめるときに伝える。
- **時刻**: 書いていなければ、終日の予定（`allDay: true`）にする。終わりの時刻がなければ、確かめるときに聞く。
- **何日かにまたがる予定**: 1 日ずつ分けて作る。件名の後ろに「（1日目）」「（2日目）」…を付け、日ごとの時刻を使う。
- **場所**: `location` に入れる。
- **メモ**: 元の文にある、日程の詳しい情報・URL などは `description` に入れる。
- タイムゾーンは、ユーザーが書いたときだけ `timeZone` に入れる。書いていなければ入れない（コネクタが決める）。

## 4. 作る前に確かめる

- 作る前に、毎回内容を見せて、OK をもらう。何件かあるときは表にする（登録先・件名・日時・場所）。
- 年や時刻を補ったところは、補ったことがわかるように書く。
- 同じ日に同じ件名（「（1日目）」などを除いて）の予定がすでにないか、`list_events` で調べる。あれば、そのことも書く。
- 直すように言われたら、直して、もう一度確かめる。

## 5. 作って報告する

- `create_event` で、1 件ずつ作る。
- 作った予定の件名・日時と、結果にあるリンク（htmlLink など）を報告する。失敗したものがあれば、エラーの文をそのまま書く。
